## 무엇을 만드나요
지금은 하루 한 번 만든 "스냅샷"을 GitHub Pages에 올리는 구조예요. 이걸 **페이지를 열 때마다 최신 데이터를 가져오는 구조**로 바꿔요. GitHub Pages는 정적 호스팅이라 실시간 수집이 안 되기 때문에, 화면은 BAZE 호스팅(`<이름>.baze.cloud`)으로 옮겨요.

## 화면과 흐름
- 화면 구성은 지금과 같아요: 날씨, 주요 지수, 관심 종목, 정부 소식, 영문 뉴스, 국내 뉴스 탭.
- 페이지를 열면 먼저 화면 틀이 뜨고, 각 구역이 따로따로 최신 데이터로 채워져요. 느린 뉴스 사이트 하나 때문에 전체가 기다리지 않아요.
- 상단에 "마지막 갱신 시각"과 **새로고침 버튼**이 생겨요.
- 자동 갱신 주기: 지수는 약 1분, 날씨는 30분, 뉴스는 5분마다 화면이 스스로 바뀌어요. 탭이 백그라운드이면 쉬어요.
- 어떤 구역의 수집이 실패하면 그 구역에만 "불러오지 못했어요. 다시 시도" 안내가 나오고 나머지는 정상 표시돼요. 직전에 받은 데이터가 있으면 그걸 보여 줘요.
- 폰에 설치한 앱(홈 화면 아이콘)도 같은 주소를 열기 때문에 그대로 실시간이 돼요.

## 저장되는 것
사용자가 입력하는 정보는 없어요. 수집한 데이터는 서버에 잠깐(수 분) 보관해서 접속자가 많아도 뉴스 사이트에 매번 요청하지 않게 해요.

## 이용 방식
공개 링크 하나로 누구나 열어요. 기존 GitHub Pages 주소는 새 주소로 안내만 남기거나 내려요(선택).

## 제가 정한 것
- 새 주소 이름은 `morning-news-bot`으로 시도하고, 쓰고 있으면 다른 이름을 써요.
- 관심 종목, 뉴스 출처, 수원 날씨 등 지금 설정은 그대로 가져가요.
- 원본 Streamlit 앱 파일은 지우지 않고 남겨 둬요.

## 이번 버전에서 하지 않는 것
- 증시 틱 단위 초실시간 시세(수초 단위)는 제외해요. 무료 시세 출처가 지연·제한이 있어요.
- 로그인, 개인별 설정 저장, 알림은 없어요.
- 안드로이드 APK 제작은 하지 않아요.

## 어떻게 확인하나요
미리보기에서 각 구역이 채워지는지, 새로고침 버튼이 최신 시각으로 바뀌는지, 일부 출처를 막았을 때 그 구역만 오류 안내가 나오는지, 폰 화면 폭에서 깨지지 않는지 확인해요. 배포 후 실제 주소에서도 한 번 열어 봐요.

## 미리 알아둘 점
지금 샌드박스에서 막혔던 정부 소식(korea.kr)은 새 서버에서도 막힐 수 있어요. 그 경우 그 탭에만 안내가 표시돼요.
